# HausaTranslatorAI

## English–Hausa Translation System

HausaTranslatorAI is a Python-based English-to-Hausa translation system developed using a custom English-Hausa translation dataset.

The project provides a local web-based interface for translating English text into Hausa and is designed as a practical language technology project that can be continuously expanded with additional linguistic data and translation capabilities.

## Features

- English-to-Hausa translation
- Custom English-Hausa translation dataset
- 4,222 English-Hausa translation entries
- Translation memory
- Python-based translation engine
- Flask web application
- Local web interface
- UTF-8 support for Hausa text
- Expandable translation dataset

## Technologies

- Python
- Flask
- Pandas
- NumPy
- CSV
- HTML/CSS
